Tes contacts servent uniquement à ton tri.

Swipe n Sort recherche les doublons, affiche les informations à conserver et te laisse valider les fusions. Le traitement s’effectue dans ton navigateur.

Fichiers locaux

Les fichiers vCard sont lus dans l’onglet, sans envoi vers un serveur. Un export télécharge une copie sur ton appareil. Aucune modification n’est envoyée à un service de contacts à partir d’un fichier importé.

Connexion Google

Quand tu choisis de connecter Google, la bibliothèque officielle Google ouvre son écran de consentement. La première autorisation lit tes contacts. Si tu choisis ensuite « Appliquer dans Google », une autorisation distincte permet de modifier les fiches conservées et de supprimer les doublons indiqués dans le récapitulatif. Les échanges vont directement de ton navigateur aux API Google, sans serveur intermédiaire Swipe n Sort.

Les contacts et les jetons d’accès sont conservés uniquement en mémoire dans l’onglet. L’app ne les enregistre pas dans un stockage persistant du navigateur ou dans le dépôt GitHub. Tu peux télécharger volontairement une sauvegarde locale. Fermer ou recharger la page efface la session de l’app. Les autorisations accordées à Google restent gérées par Google et peuvent être révoquées depuis ton compte ou par la déconnexion proposée dans l’app.

Usage des données

L’app n’a pas de publicité, d’analyse d’audience ni d’IA distante. Elle ne vend pas tes contacts et ne les utilise pas pour entraîner de modèle. L’usage des données reçues des API Google se limite aux fonctions de tri et de gestion des contacts que tu déclenches.

GitHub Pages héberge le code public. GitHub et Google appliquent leurs propres règles aux requêtes adressées à leurs services ; l’app ne leur envoie pas le contenu d’un carnet local. Les extensions et outils de ton navigateur restent hors du contrôle de Swipe n Sort.

Signaler un problème

Le dépôt public permet de signaler un problème. N’y joins jamais ton carnet, tes jetons, une sauvegarde personnelle ou une capture contenant des coordonnées.
